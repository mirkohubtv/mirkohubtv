# Hey, I'm Mirko

I'm an independent developer from Italy, better known online as MirkoHubTV. I build Discord bots, backend services and the infrastructure that keeps them running.

My main project is Local Hub, a Discord bot that helps FiveM roleplay communities handle invoicing, employee time tracking and everyday business operations. I also build automation tools for community management, plus backend services like a ban system called HALT and a self-hosted IPv4 to IPv6 proxy for my own domains.

I mostly write Python and work with FastAPI, MongoDB, Docker and Linux servers. I enjoy troubleshooting, optimization and infrastructure work, and I care about building systems that solve real problems in a clear and efficient way.

If you are launching a server or need custom automation, I'm open to collaboration. **Please don't contact me if your project involves LLMs.**

You can find me at https://mirkohubtv.it
